# 🗄️ CRUD de Usuários em Python

Este projeto é uma aplicação simples de **CRUD (Create, Read, Update, Delete)** desenvolvida em Python utilizando banco de dados SQLite.

O sistema roda no terminal e permite gerenciar usuários através de um menu interativo.

## 🚀 Tecnologias utilizadas

- Python
- SQLite
- SQL

## 📌 Funcionalidades

O sistema permite:

✔ Criar usuários  
✔ Listar usuários cadastrados  
✔ Atualizar dados de usuários  
✔ Deletar usuários  

Todos os dados são armazenados em um banco de dados local.
